Команда OpenDesign представила Motion — инструмент для создания анимационных роликов с помощью ИИ-агентов. В анонсе обещают возможность выбирать агента и модель. Презентационный ролик запуска, по словам авторов, целиком сделан в OpenDesign.
В открытом репозитории описан видеопроцесс OpenDesign: агент создаёт HTML, CSS и GSAP-анимацию, а HyperFrames собирает из неё MP4 через браузер и FFmpeg. Исходные файлы остаются в проекте, поэтому работу можно продолжать правками через агента.
Такой подход подходит для короткого промо продукта, анимированных графиков и заставок. Для этих сценариев в репозитории есть готовые шаблоны.
Сам OpenDesign открыт под лицензией Apache-2.0. Использование подключённого агента или API оплачивается по условиям выбранного сервиса.
